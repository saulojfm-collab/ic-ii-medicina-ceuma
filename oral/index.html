Histórico de sorteios

    Acesso do professor

    Entre para avaliar e conduzir o sorteio. Compartilhe com a turma somente o link da sala de sorteio.

    Notas e comentários ficam criptografados neste navegador. Para usar outro aparelho, importe o backup com a mesma senha. Limpar os dados do navegador sem backup elimina os registros.

    Área do professor. As notas ficam neste navegador, protegidas pela senha. Faça backup ao terminar. O servidor transmite somente a turma, a equipe e o nome sorteado. O sorteio online pode levar alguns instantes para iniciar no serviço gratuito.

    Equipes e avaliações

    Identificação

    Ao alterar integrantes, confira a lista de notas. O sorteio considera os nomes atualmente informados e mantém o histórico.

    Sorteio para a turma acompanhar

    Um novo sorteio para a mesma equipe exige confirmação. O histórico público é temporário e pode ser republicado pelo professor a partir do registro salvo no navegador.

    Critérios da apresentação oral

    Preencha as cinco notas. A soma vale até 5,0 pontos. Este painel não calcula a nota do trabalho escrito, que vale outros 5,0 pontos.

    Total: pendente / 5,0

    A aplicação é opcional e exige confirmação. Você pode ajustar as notas de cada aluno abaixo.

    Registro por aluno

    D = domínio e evidências (2,0). O = organização e tempo (1,0). C = comunicação (1,0). V = recursos visuais (0,5). R = interação e respostas (0,5).
